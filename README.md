# spinoza-ethics-site

Build script for a static, offline-capable scholarly workbench for Spinoza's
*Ethics*. It reads an unpacked Calibre EPUB export of the Curley translation of
the *Collected Works* and writes a self-contained website: no server, no runtime
dependencies, installable as a PWA.

The generated output is roughly 89MB and includes:

- 295 canonical Ethics node pages (definitions, axioms, propositions,
  demonstrations, corollaries, scholia), each with its incoming and outgoing
  references.
- The full source text, images and fonts, rewritten with cross-reference links.
- A derived SQLite database, `spinoza-ethics.db`, with FTS5 full-text search and
  recursive-CTE dependency chains over the reference graph.
- CSV and JSON exports of the same node/edge data.
- A service worker and web app manifest for offline use.

## Install

```sh
pip install -e .
pip install -e ".[dev]"   # adds pytest
```

Python 3.10 or newer. The package is stdlib-only (`xml.etree`, `sqlite3`, `csv`,
`json`, `html`, `string.Template`, `importlib.resources`).

## Usage

```sh
spinoza-build --source /tmp/spinoza_work --output build
python -m spinoza_ethics            # equivalent module entry point
spinoza-build --help                # all options
```

`--source` defaults to `/tmp/spinoza_work` and `--output` to `build/` in the
repository root.

## Source corpus

The build requires the unpacked EPUB working directory (a `text/` tree of XHTML
files plus `images/`, `fonts/`, `cover.jpeg` and `titlepage.xhtml`). It is **not**
part of this repository and must be supplied separately via `--source`. The
Ethics-focused subset of files, their labels, and which of them contain the
Ethics proper are declared in `src/spinoza_ethics/config.py`.

## Repository layout

Package source lives under `src/spinoza_ethics/`.

| Module | Role |
| --- | --- |
| `cli.py` | Argument parsing; `spinoza-build` entry point. |
| `__main__.py` | `python -m spinoza_ethics` wrapper around the CLI. |
| `config.py` | `BuildConfig` (source/output paths) plus corpus constants: core file list, document labels, Ethics files, copied assets. |
| `xmlutil.py` | Helpers over `xml.etree` for parsing and rewriting the source XHTML (local names, text content, href absolutization, serialization). |
| `codes.py` | Parsing, classification and ordering of canonical node codes such as `IP11` or `IVD2`. |
| `corpus.py` | Single extraction pass over the source documents, producing the `Corpus`: records, anchors, incoming/outgoing links, search records and Ethics nodes. |
| `graph.py` | Traversal over the node graph: edge typing, direct dependencies/uses, and bounded transitive chains. |
| `database.py` | Writes `spinoza-ethics.db` from the corpus, including the FTS5 index. |
| `exports.py` | The browser data payloads (`assets/site-data*.js`) and the CSV/JSON graph exports. |
| `pwa.py` | Service worker and web app manifest generation. |
| `templating.py` | Template loading via `importlib.resources` and `string.Template` substitution. |
| `builder.py` | Orchestrates the build: extract, render, database, exports, assets. |
| `render/documents.py` | Rewrites the source documents into site pages. |
| `render/site.py` | Top-level pages (index, apparatus, resources). |
| `render/nodes.py` | The per-node dossier pages and node index. |
| `render/fragments.py` | Reusable HTML fragments shared by node pages and dossiers. |
| `templates/` | HTML templates shipped as package data. |
| `static/` | CSS and JavaScript shipped as package data. |
| `tests/` | Pytest suite. |

The package was extracted from a single 3,538-line script,
`build_spinoza_ethics_site.py`, removed in the commit that introduced this
layout and still available in git history.

## Database

See [GRAPH_MODEL.md](src/spinoza_ethics/templates/GRAPH_MODEL.md) for the
schema, edge types and example queries (direct dependencies, direct uses,
transitive dependency chains, full-text search). It ships as package data and
is copied into the built site.

## Deployment

The site is hosted on OpenAI Sites (project id in `.openai/hosting.json`),
which serves the build through a worker:

- `deploy/worker.js` — request handler: adds security and cache headers, maps
  `/` to `/index.html`, and falls back to `<path>/index.html` for extensionless
  paths. Hand-written; not generated by the build.
- The deploy package expects the worker at `dist/server/index.js` and the
  static files under `dist/client/`, both assembled from `build/`.

## Generated output

Only source is tracked. `build/`, `dist/`, `spinoza-ethics.db` and release
tarballs are gitignored.
